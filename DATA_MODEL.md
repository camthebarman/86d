# Data model

The entities the SaaS version needs. Nothing here is implemented as a database
yet — this is the target the current JSON shapes are being steered toward.

## Rules that apply to every table

- **`id`** — `uuid`, primary key, generated by the database (`gen_random_uuid()`).
  The app can mint one too (`platform/ids.js`); both are UUID v4.
- **`organization_id`** — `uuid not null references organizations(id)` on every
  restaurant-owned table, indexed, and the subject of every RLS policy. A table
  without it is either global reference data or a bug.
- **`created_at` / `updated_at`** — `timestamptz not null default now()`.
  Written by the database, never by the client.
- **`deleted_at`** — `timestamptz null`. Soft delete, because a manager who
  deletes a recipe used by three events needs an undo, and because an audit log
  that references vanished rows is not an audit log.
- **`seed_key`** — `text null`. Set on shipped demo records so a future seed
  update can find them. **Not** a primary key.
- Money is `numeric(12,4)`, not float. Quantities are `numeric(14,4)`.
  Percentages are `numeric(5,2)` (a yield of 82.50).
- Uniqueness is always scoped: `unique (organization_id, name)`, never
  `unique (name)`.

Legend: **R** required · *o* optional

## Food and beverage

a data one, and merging them removes a whole class of duplication.

| Field | | Notes |

new `TableJoin` entity and an explicit decision, not a schema drift.

## Seeding

Two starting states, and they must not mix:

- **Empty restaurant** — every table empty except Organization, User,
  OrganizationMember and one FloorPlan. What a paying customer gets.
- **Demo restaurant** — `organizations.is_demo = true`, populated from the
  current Generic Bar & Grill seed with `seed_key` set on every row.

The current merge-on-load behaviour (new shipped items appear in existing data,
keyed by `sinceVersion`) is right for a demo and wrong for a customer:
appearing inventory is a bug when someone is counting against it. After the
migration, seed merging applies only where `is_demo`.
